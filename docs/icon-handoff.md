# Icon hand-off (designer pack)

`docs/icon-inventory.csv` lists every icon in the app (image files, ~150 inline vector icons, every map marker): ID, group, rendered size, viewBox, stroke, colour mode, where it is used and its source in the code.

Created 2026-10-26 (app 1.421.0) for the owner's designer. The designer returns files with the same names as the pack (`inline-icons-svg/<group>/<id>.svg`, `map-pins/*.svg`, `app-icons/*.png`); the ID column maps each file back to the code:

| Kind | Where it lives | How to replace |
|---|---|---|
| Image files | `client/public/icons/**`, `client/public/brand/*` | overwrite the file, add new paths to `APP_SHELL` in `client/public/sw.js` if any are new |
| Inline vector icons | `client/public/js/icons.js`, `filterIcons.js`, `util.js` (tier + category), `views/orders.js` (order status, `ORDER_STATUS_ICONS`), `views/settings.js` (settings tiles), plus one-offs listed in the CSV | paste the new `<path>` content into the same key; keep the wrapper (class, 24 px viewBox, stroke attrs) |
| Map pins | `client/public/icons/markers/*` generated by `scripts/make-pin-art.mjs` (customer / competitor) + PNG for potential | edit the script (body outline + glyphs); the ring files are derived from the body outline |
| CSS-drawn markers | `client/public/css/map-marker-system.css`, `styles.css` (`.pin-*`, `.me-dot`, `.pin-cluster`, `.brand-dot`, `.pin-debt`) | edit the CSS tokens/sizes |

Known clean-ups to do together with the replacement: merge the pasted copies of the back arrow (about 33 places) and the close X (about 10) into shared icons; `icons.door`, `icons.shield` and `icons/categories/blue-*.png` are unused.

After replacing anything under `client/public/`: bump `APP_VERSION` and `CACHE_VERSION`, run `npm run verify:ui` and the map e2e specs, and look at light + dark mode on a phone-width screen.
